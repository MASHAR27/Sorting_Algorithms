# Sorting Algorithms Implemented

## What is it

I implement the various sorting algorithms for iterables like list(Array) in ascending order

### Bubble Sort

It iterates over each the array each time bubbling the largest value till the end, it compares adjacent indices to see which is larger, if array[i] is larger than array[i+1] then array[i] goes in the position of i+1 and vice versa, thus this goes for at least n-1 passes(rounds) in worst cases until all the numbers are sorted but in good scenarios basically when there is no switching of elements for the entire round then the sorting is done already.
